# Firefly brand assets

Icon concept N ("Trail bubble"): a speech bubble with a glowing amber orb inside and a red trail of dots for its tail.

| File | Use |
|---|---|
| `firefly-icon.svg` | Master icon, for light backgrounds |
| `firefly-icon-dark.svg` | For dark backgrounds (bubble is `#F2EFEA`) |
| `firefly-icon-{16,32,180,192,512}.png` | Raster exports (180 = apple-touch-icon, 192/512 = PWA manifest) |
| `favicon.ico` | 16/32/48 multi-size favicon |

Palette: red `#DB3440`, amber `#FAAF3F`, halo `#FDE3B8`, charcoal `#4A4A4A`.
