# Firefly brand assets

Icon concept S ("Bubble jar"): a jar shaped like a speech bubble, with a red lid and two amber firefly lights inside.

| File | Use |
|---|---|
| `firefly-icon.svg` | Master icon, for light backgrounds |
| `firefly-icon-dark.svg` | For dark backgrounds (outline is `#F2EFEA`) |
| `firefly-icon-{16,32,180,192,512}.png` | Raster exports (180 = apple-touch-icon, 192/512 = PWA manifest) |
| `favicon.ico` | 16/32/48 multi-size favicon |

Palette: red `#DB3440`, amber `#FAAF3F`, charcoal `#4A4A4A`.
